# Chaos Crew – Il simulatore del caos

Gioco online multiplayer (fino a 8 giocatori) nel browser: lavori normali in situazioni assurde.
Primo livello: **Cantiere**. Stanze private con codice d'invito, partite da 2 minuti, imprevisti, negozio di cappelli, colori e attrezzi.

Gioca: https://brabas-games.github.io/chaos-crew/

Multiplayer peer-to-peer con [PeerJS](https://peerjs.com/). Tutto il gioco è in `index.html`.
